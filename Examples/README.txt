Example corpora for GridPuzzle.

Supported puzzle families include Futoshiki, Hidato, Kakuro, KenKen, Killer Sudoku, Latin Squares, Numbrix, Slitherlink, and Sudoku.

The retained Hidato, Kakuro, Numbrix, and Slitherlink CSP-Rules files are active runtime inputs and are exercised by scheduled isolated corpus jobs.

Where applicable, source websites or authors are identified by the nested folder names and local README files.
